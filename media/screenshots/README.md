# Screenshot Index

Screenshots of Stunt Car Racer (Amiga, 1989) organised by category.

## How to obtain screenshots

Due to network restrictions during initial research, screenshots must be manually downloaded from these sources:

### Primary sources (best quality)
- **The King of Grabs** — https://thekingofgrabs.com/2017/12/28/stunt-car-racer-amiga/
- **MobyGames** — https://www.mobygames.com/game/782/stunt-track-racer/screenshots/amiga/
- **Hall of Light** — https://hol.abime.net/2160
- **Lemon Amiga** — https://www.lemonamiga.com/game/stunt-car-racer
- **Internet Archive** (direct PNGs) — https://archive.org/download/Stunt_Car_Racer_1989_MicroStyle_cr_QTX/
